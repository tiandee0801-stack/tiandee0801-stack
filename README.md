## 精选项目

### DeeStride 脚踝运动复训系统

脚踝复训服务的 Web 原型，把筛查建档、训练反馈、视频观察、人工复核和阶段报告串在一起。我负责产品分层、训练反馈流程和人工复核机制的设计。

在线版可用示例档案体验全流程及骨架回放。新视频的姿态推理在配置模型的本地版运行。

[在线体验](https://tiandee0801-stack.github.io/ankle-rehab-demo/) · [源码与运行说明](https://github.com/tiandee0801-stack/ankle-rehab-demo)

### Life Fitness AI Coach

面向居家健身的交互 Demo，展示教练咨询、单个动作视频观察和训练记录。我负责设计教练服务流程、知识使用要求和反馈方式。

在线版使用预设教练讲解和示例视频，真实模型调用需要本地环境。
